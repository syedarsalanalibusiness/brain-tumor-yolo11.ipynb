## 1. Abstract

This project develops an object-detection model for brain tumor MRI images using YOLOv11. The supplied dataset contains bounding-box annotations for two tumor types: Astrocytoma and Glioblastoma. The model is trained on the training split, tuned using the validation split, and evaluated once on the independent test split. The final system predicts both tumor category and tumor location. It is a coursework prototype, not a clinical diagnostic tool.

## 2. Problem Statement

Manual examination of MRI scans is time-consuming and requires specialist expertise. The aim of this work is to investigate whether a deep-learning detector can automatically locate suspected tumor regions and label them as Astrocytoma or Glioblastoma.

## 4. Dataset Description

The archive `brain.yolov11.zip` is organized in standard YOLO structure:

| Split | Image directory | Label directory | Use |
|---|---|---|---|
| Training | `train/images` | `train/labels` | Learn model parameters |

| Test | `test/images` | `test/labels` | Final unbiased evaluation |

Each label row follows `class_id x_center y_center width height`, where coordinates are normalized between 0 and 1. Class `0` is Astrocytoma and class `1` is Glioblastoma. The supplied `data.yaml` confirms `nc: 2`.

### Why YOLOv11?

YOLOv11 is a one-stage object detector: a single forward pass predicts bounding boxes, confidence scores, and class labels. The `nano` variant was selected because it trains quickly on a Colab GPU and is practical for a classroom demonstration. A larger model such as `yolo11s.pt` can be tested later if more GPU time is available.

## 7. Evaluation Metrics

**Precision** measures how many predicted tumor boxes are correct: `TP / (TP + FP)`.  
**Recall** measures how many real tumor boxes are found: `TP / (TP + FN)`.  
**mAP@0.50** is mean average precision when an IoU of at least 0.50 is considered correct.  
**mAP@0.50:0.95** averages mAP across stricter IoU thresholds and is the more demanding score.

Intersection over Union (IoU) is the overlap between predicted and ground-truth bounding boxes divided by their union.

## 9. Discussion

Good performance indicates that the model learned visual patterns correlated with the two annotated tumor categories. However, model scores can be affected by class imbalance, image quality, annotation quality, limited data diversity, and data leakage. A high mAP does not establish medical validity. In particular, images from the same patient must never occur across train and test splits.

Possible improvements are collecting more diverse data, verifying labels with domain experts, increasing epochs, trying a larger YOLOv11 model, applying medically appropriate augmentation, and reporting per-class metrics and error cases.

## 12. Viva Questions and Short Answers

1. **What is object detection?** It predicts an object class and its location using a bounding box.
2. **Why not use only accuracy?** Detection needs both correct class and correct localization; mAP captures this better.
3. **What is IoU?** The overlap area of two boxes divided by their combined area.
4. **Why keep a test split separate?** It gives a final estimate on images not used to make training decisions.
5. **What does confidence mean?** The model's prediction score; it is not a clinical probability.
6. **What is transfer learning?** Starting with a pretrained model and fine-tuning it on a new task.
7. **Why use `best.pt`?** It is the checkpoint with the best validation performance during training.
8. **Can this be used in hospitals?** No. It needs rigorous clinical validation, regulatory review, and safety controls.
